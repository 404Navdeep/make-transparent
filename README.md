# Make Transparent!
A small Node.js/TypeScript tool that takes images from a Pinterest board, downloads them, and removes their backgrounds using a Replicate-compatible background-removal API.
---
## Usage
### Requirements 
- NodeJS
- NPM 
- Playwright
- Typescript 
maybe ur account cookies for private things
### Steps
Clone or download the project and open cmd
1. Then run: ``cd make-trasparent``
2. Then to install run: ``npm i``
3. Create .env 
    ```.env
    REMOVEBG_KEY=
    API_BASE=
    MODEL=
    ```
4. Get ur api key from: ai.hackclub.com btw (really cool free ai)
5. Then run ``npm start -- "https://www.pinterest.com/USERNAME/BOARD`` to run.

## Features
- Extracts all images from pinterest boards.
- Removes bg from them
- Vola u have them ready for stickers
